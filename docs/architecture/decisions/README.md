# Architecture Decision Records

Architecture Decision Records capture material decisions that are expensive to reverse, affect
multiple modules, or constrain security, reliability, and operations.

## Status values

- **Proposed:** under review and not binding.
- **Accepted:** approved and binding.
- **Superseded:** replaced by another ADR.
- **Deprecated:** retained for history but no longer recommended.
